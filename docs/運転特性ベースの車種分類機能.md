運転特性ベースの車種分類機能を実装してください。（以前mainにマージした際に消えてしまったため、再実装をお願いします）

## 目的
ナビの車種情報を、見た目のボディタイプではなく「運転の難易度・注意点の違い」で
分類し、ルート検索結果（所要時間・注意点）に反映させる。

## 実装内容

### 1. 型定義（src/types.ts）
- VehicleType: 'kei' | 'standard' | 'large' | 'truck' | 'motorcycle'
- VehicleDifficulty: 'easy' | 'standard' | 'challenging' | 'hard'
- VehicleProfile 型:
  - type: VehicleType
  - name: string（表示名）
  - group: string（グループ名）
  - description: string
  - difficulty: VehicleDifficulty
  - cautions: string[]（注意点リスト）
  - speedFactor: number（速度係数。標準を1.0とした倍率）

### 2. データ定義（src/data/vehicleProfiles.ts を新規作成）
以下の5車種を VEHICLE_PROFILES（Record<VehicleType, VehicleProfile>）として定義：

- kei（軽自動車）: 小型・軽量グループ、difficulty: easy、speedFactor: 0.9
  注意点例：高速合流時の加速不足、急な上り坂での速度低下、大型車との速度差
- standard（普通車）: 標準クラス、difficulty: standard、speedFactor: 1.0
  注意点例：特段の注意点はなし（標準的な運転操作）
- large（ミニバン・SUV）: 大型ボディグループ、difficulty: challenging、speedFactor: 0.95
  注意点例：車庫入れでの車幅感覚、狭い路地での離合・バック、内輪差
- truck（トラック）: 商用・大型車グループ、difficulty: hard、speedFactor: 0.85
  注意点例：右左折時の死角、制動距離、高さ制限・重量規制
- motorcycle（バイク・原付）: 二輪グループ、difficulty: standard、speedFactor: 1.0
  注意点例：大型車の死角、すり抜け時の接触、路面のスリップ

あわせて、以下もエクスポートすること：
- VEHICLE_PROFILE_LIST（配列版、UIでの一覧表示用）
- VEHICLE_ICONS（lucide-reactのアイコンを車種ごとに割り当て：
  kei→CarFront, standard→Car, large→Bus, truck→Truck, motorcycle→Bike）

### 3. UI連携（src/components/RoutePanel.tsx）
- 車種選択ボタンをVEHICLE_PROFILE_LISTから生成し、選択中の車種をハイライト
- 選択中の車種のdescriptionを表示
- ルート検索結果に、選択車種のcautions（注意点）を表示する

### 4. ルート計算への反映（src/services/mapService.ts）
- calculateRoute関数にvehicleType引数（デフォルト'standard'）を追加
- mode === 'driving' のときのみ、VEHICLE_PROFILES[vehicleType].speedFactor を
  所要時間計算に掛け合わせる
- mode === 'driving' のときのみ、VEHICLE_PROFILES[vehicleType].cautions を
  結果（RouteResult.cautions）に含める

### 5. App.tsx側の状態管理
- vehicleType の state（デフォルト'standard'）を追加
- 車種変更時にトースト通知（例：「車種を〇〇に切り替えました」）
- 車種変更時、既にルート結果があれば再計算する
